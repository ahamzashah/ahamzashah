#### 🤖 How I use AI in my dev workflow
 
I use **Claude Code** and the **Claude Agent SDK** every day, mainly to make engineering work repeatable and safe, not just faster:
 
- **Ticket → deploy loops.** Agents pick up a Jira ticket, implement it, open the PR and run tests. After deploy, they check the result in a real browser with **Playwright MCP**.
- **Reusable skills.** I keep skills for Jira, implementation, UI work, PRs, testing, security review, PR → QA hand-off and production deploys.
- **Persistent context.** Each repo has its own context files (Azure Functions, React, Node.js, legacy .NET), so agents start with the right knowledge.
- **Security by rules, not hope.** Guardrails live in hooks and rules, so a model can't simply skip them.
- **Token-aware scripts.** Long steps run as scripts, which keeps agent runs cheaper and more predictable.
- **Model choice by task.** I pick the model to match the job instead of using one for everything.
- **LLM features in products.** For example, a name-splitting service built on the Anthropic API, and an AI-assisted workflow that creates unit-test data.
I'm cleaning up some of these workflows to share here. More coming soon.
